Start with a `Dockerfile` at the repository root. Zenith can build your app image before submission, or you can use a public image. Any other services need public images.

<Info>
    Zenith currently requires a root `Dockerfile` when you submit, even if `zenith-compose.yml` uses only prebuilt images. It will not rebuild those images. If you already have a Dockerfile, continue to [creating `zenith-compose.yml`](/content/zenith-compose).
</Info>

## 1. Prepare a Dockerfile

If you have a production Dockerfile, use that. Otherwise, follow Docker's guide for your language or framework.

### Check the runtime

To be compatible with the Zenith platform, each container must:

- Support `linux/amd64` architecture
- Read deployment-specific values and secrets from environment variables; use [inline Compose configs](/content/zenith-compose#add-static-configuration) for static, non-secret files
- Write logs to `stdout` and `stderr`
- Listen on `0.0.0.0`, not `localhost`
- Store any persistent data in a documented directory
- Start using only the container image, declared environment variables, config files, and volumes

<Warning>
Do not copy `.env` files, private keys, registry credentials, or other secrets into the image. Secrets MUST only be supplied via environment variables.
</Warning>

## 2. Choose an image source

Choose one option for your app service:

- **Let Zenith build it:** Set `build: .` in `zenith-compose.yml`. Zenith builds the root `Dockerfile` before submission. Do not also set `image` on that service.
- **Use a public image:** Set `image` to an image anyone can pull, whether you publish it or its maintainers do. GHCR and Docker Hub are options.

Other services need public `image` references. Zenith does not build images when it deploys an app.

If you publish an image yourself, these guides can help:

<Columns cols={2}>
  <Card title="Publish to GHCR" icon="github" href="https://docs.github.com/en/actions/tutorials/publish-packages/publish-docker-images#publishing-images-to-github-packages">
    Use GitHub Actions to build and publish an image to `ghcr.io`.
  </Card>
  <Card title="Publish to Docker Hub" icon="docker" href="https://docs.docker.com/docker-hub/repos/manage/hub-images/push/">
    Tag and push an image to a public Docker Hub repository.
  </Card>
</Columns>

<Warning>
New GHCR packages are private by default. Before continuing, follow GitHub's [package visibility guide](https://docs.github.com/en/packages/learn-github-packages/configuring-a-packages-access-control-and-visibility) to make the image public. GitHub warns that a public package cannot be made private again.
</Warning>
